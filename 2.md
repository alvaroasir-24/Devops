# 2. Herramientas de CI/CD

## Conceptos clave
Las siglas **CI/CD** representan dos prácticas fundamentales del desarrollo moderno de software:

* **CI (*Continuous Integration* / Integración Continua):** Probar el código constantemente.
* **CD (*Continuous Delivery* o *Continuous Deployment*):** Entregar y desplegar el software automáticamente.

> **Regla fundamental:** CI es la base sobre la que se construye CD.

---

## CI: Integración Continua
- **¿Qué es?** Práctica en la que los desarrolladores suben y combinan sus cambios de código en un repositorio central de manera frecuente.
- **Objetivo:** Detectar fallos tempranamente y verificar que las nuevas funcionalidades se integren sin romper el sistema existente.
- **Funcionamiento:** Tras cada subida (*push*), se ejecutan pruebas automáticas. Si alguna prueba falla, el equipo recibe una alerta inmediata para corregirla al momento.

---

## CD: Continuous Delivery vs. Continuous Deployment

| Concepto | Descripción | Despliegue a Producción |
| :--- | :--- | :--- |
| **Entrega Continua (*Continuous Delivery*)** | El software validado en CI se compila y empaqueta automáticamente quedando listo para producción. | **Manual** (mediante confirmación de un solo clic). |
| **Despliegue Continuo (*Continuous Deployment*)** | Todo cambio que supere con éxito las fases de CI y pruebas pasa directamente a producción. | **Automático** (sin intervención humana). |

---

## Distribución de responsabilidades por fases

- **Fases dominadas por Desarrollo (Dev):** `Plan`, `Code`, `Build`, `Test`.
- **Fases dominadas por Administración / Operaciones (Ops):** `Release`, `Deploy`, `Operate`, `Monitor`.
